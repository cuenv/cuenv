# cuenv 0.70.1

## Restore release binaries

Fix matrix job architecture selection so release builds receive the correct `CUENV_ARCH` value on Linux x64, Linux ARM64, and macOS ARM64 ([#579](https://github.com/cuenv/cuenv/pull/579)). A task environment passthrough previously overwrote the selected architecture, causing the 0.70.0 binary builds to fail.

This patch restores binary publishing and includes all changes from [0.70.0](0.70.0.md).
