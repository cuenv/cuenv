# cuenv 0.58.1

## Fix: directories named like files in recursive evaluation

Since 0.57.0, recursive evaluation listed each package directory to the CUE
loader as `./dir`. The loader reads an argument with an extension as a file,
so a directory named like a domain or a file (`projects/podcast.fm`,
`schema.cue`) failed with `unknown file extension .fm`.

The infrastructure project-name check failed closed, so `cuenv infrastructure
plan`, `apply` and `import` errored in any module with such a directory.
Workspace evaluation (`sync`, `ci`, cross-project tasks) fell back to slower
per-directory evaluation. Directories are now passed with a trailing slash.
See [PR #522](https://github.com/cuenv/cuenv/pull/522) and
[#520](https://github.com/cuenv/cuenv/issues/520).
