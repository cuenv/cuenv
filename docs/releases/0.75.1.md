# cuenv 0.75.1

This release publishes the CUE schema module of the changes in
[0.75.0](0.75.0.md). The 0.75.0 binaries, Homebrew formula and docs shipped,
but `cue mod publish` refused the module as untidy, so the schema the 0.75.0
binary needs never reached the registry. Upgrade the binary and the schema
together:

```sh
cue mod get github.com/cuenv/cuenv@v0.75.1
```

Read the [0.75.0 notes](0.75.0.md) for what changed: task references through
imports, file references, the removal of `..` inputs and `#ProjectReference`,
and the other breaking changes.

## Fixes

- The schema-compat module fixtures under
  `tests/schema-compat/testdata/modules` are CUE modules of their own, so their
  imports of `example.com/consumer` are no longer packages of
  `github.com/cuenv/cuenv` ([#621](https://github.com/cuenv/cuenv/pull/621)).
- `ci.schema-compat` runs `cue mod tidy --check` on the module a release
  publishes, which catches this before a release.
