# cuenv 0.70.2

## Reliable release jobs

Release jobs now put the realized `.#cuenv` Nix package on `PATH` instead of comparing it byte-for-byte with a bootstrap artifact ([#580](https://github.com/cuenv/cuenv/pull/580)). Two builds of the same store path can differ in bytes, which failed the 0.70.1 release.

## Faster release binaries and pull requests

- The linux-arm64 release binary is cross-compiled on x86 and smoke-tested under emulation, which cuts its build from about 14 minutes to about 5 ([#581](https://github.com/cuenv/cuenv/pull/581)). A native ARM job still builds and checks the Nix package after each merge to `main`.
- Pull requests run x86 Linux checks only. macOS checks run in `cuenv-darwin` after merge ([#580](https://github.com/cuenv/cuenv/pull/580)).
- A manual `cuenv-release-dry-run` workflow builds all three release binaries without publishing ([#581](https://github.com/cuenv/cuenv/pull/581)).
