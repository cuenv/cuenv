# cuenv 0.71.0

## Run CI tasks without bootstrapping cuenv

A task can set `ci: github: execution: "direct"` to run its command straight from the generated GitHub workflow instead of through `cuenv task` ([#582](https://github.com/cuenv/cuenv/pull/582)). Its job no longer waits for a cuenv build or sets up secrets. Compilation rejects the setting when the task's environment needs cuenv to resolve secrets or passthrough values; the matrix `CUENV_ARCH` passthrough is the only exception.

cuenv's own `cargo.build` uses it, so release binaries start building as soon as the release is published, and only one x86 cuenv build remains for the publishing jobs.

This release includes all changes from [0.70.2](0.70.2.md).
