# cuenv 0.76.1

## Generated workflows run on Node 24

Jobs that upload or download artifacts no longer print the "Node.js 20 is
deprecated" annotation. Generated workflows and contributors now pin the first
release of each action that runs on Node 24
([#627](https://github.com/cuenv/cuenv/pull/627)):

| Action | Before | After | Where |
|---|---|---|---|
| `actions/upload-artifact` | v4 | v7 | matrix, release and infrastructure workflows |
| `actions/download-artifact` | v4 | v8 | matrix, release and infrastructure workflows |
| `actions/github-script` | v7 | v9 | infrastructure plan comment and reviewed-plan lookup |
| `actions/setup-go` | v5 | v7 | `cuenv.setup.go` contributor |
| `mozilla-actions/sccache-action` | v0.0.9 | v0.0.11 | sccache contributor |
| `codecov/codecov-action` | v5 | v7 | codecov contributors |

Run `cuenv sync ci` to pick up the new versions.

`actions/download-artifact@v8` fails the job when a downloaded artifact's digest
does not match the one GitHub recorded, where v4 only warned. Self-hosted runners
need Actions Runner 2.327.1 or later for Node 24 actions.
