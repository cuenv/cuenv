# cuenv 0.81.1

## Features

GitHub Actions workflow generation has four new options ([#730](https://github.com/cuenv/cuenv/pull/730)):

- Set `name` and `file` on `#GitHubConfig` to choose a workflow's display name and file stem.
- Set `token: false` on a pipeline or task to omit cuenv's default `GITHUB_TOKEN` from step environments. A token explicitly set by a task is retained.
- Set `jobPermissions: "inferred"` to grant each job the permissions its tasks need under a top-level `permissions: {}`.
- Set `jobName` on a task to choose the job's display name without changing its ID.

Run `cuenv sync ci` after adopting these options to regenerate workflows.
