# cuenv 0.73.0

## Infrastructure plans you can read

`cuenv infrastructure plan` no longer prints each attribute as one line of compact JSON ([#605](https://github.com/cuenv/cuenv/pull/605)). A text plan now has three parts:

- **Table**: every data source read and every resource with work, with the attributes an update or replacement touches.
- **Changes**: one diff per change. Long values are laid out over several lines with `+`, `-` and `~` in a fixed column. An update shows only what differs, and list elements are matched by likeness, so an edited element is a change and not a removal plus an addition.
- **Resources**: the totals.

## Secrets providers in CI

A context's environment-specific variables now count towards a pipeline's secrets providers only when the pipeline selects that environment ([#608](https://github.com/cuenv/cuenv/pull/608)). Before, a context that set an `op://` reference under `environment: production` gave every pipeline the 1Password setup and `OP_SERVICE_ACCOUNT_TOKEN`, including pull request and infrastructure plan workflows that could never resolve it. A context's base variables still count for every pipeline.

## Cuetty

- **Copy last command output** in the palette copies what the last command printed, without its prompt or command line. It needs a shell that marks output with OSC 133 ([#606](https://github.com/cuenv/cuenv/pull/606)).
- The active tab's ring and the unread dot no longer share the accent colour, which is left to the bell.

## Fixes

- The BDD harness stops the hook supervisors each scenario started, so the Nix check no longer races them when it removes its build directory ([#607](https://github.com/cuenv/cuenv/pull/607)).
