# cuenv 0.73.1

## Fixes

- `cuenv ci` passes a task's own secrets to it ([#609](https://github.com/cuenv/cuenv/pull/609)). A secret set in a task's `env` reached the task unset under `cuenv ci`, though `cuenv task` resolved it. The CI executor now resolves a task's `env` as `cuenv task` does and redacts the secrets it resolves.
