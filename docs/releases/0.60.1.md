# cuenv 0.60.1

## Sync

- `cuenv sync -A` now writes the generated infrastructure provider types in
  `cue.mod/gen` before any other provider evaluates projects. In a fresh
  checkout, such as a CI runner, projects that import those types were
  skipped, so their `infrastructure.workflows` were not generated. 0.60.0
  announced this fix but reordered the wrong list.
- Managed `.gitignore` sections (`cuenv vcs`, `cuenv infrastructure`) are
  rewritten in place. Before, every sync moved a section to the end and left
  its separating blank line behind, so the file gained blank lines on every
  run. Removing a section now also removes its separator.

## Infrastructure workflows

The plan and apply workflows list only the CUE files outside
`<project>/**` and `cue.mod/**`, which already match the rest.

See [PR #526](https://github.com/cuenv/cuenv/pull/526).
