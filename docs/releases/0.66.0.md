# cuenv 0.66.0

## Cuetty

The experimental Cuetty terminal now reads font size, line height, per-edge
padding, and transparency from global and per-directory CUE configuration.
The session-only Settings page has been removed; see the
[Cuetty configuration guide](../src/content/docs/explanation/cuetty.md#cuetty-cue-configuration)
for the available fields and defaults.

Wheel input now reaches applications using supported terminal mouse modes,
including Codex, and new windows focus the terminal for keyboard input. The
changes have automated Linux PTY coverage and an isolated Linux Codex smoke
check; physical desktop input and macOS still need interactive verification.

Cuetty is a separate experimental application and is not included in the cuenv
CLI release binaries.

## Documentation

The documentation site has moved from Starlight to Nimbus on Astro
([#564](https://github.com/cuenv/cuenv/pull/564)).
