# cuenv 0.79.0

## Upgrade notes

- **Generated files are kept current by every command.** Outside `cuenv sync`, each command now refreshes `scripts.gen.cue`, codegen files and `.rules.cue` outputs once per project when their inputs changed, using fingerprints in `.cuenv/autosync.json`. This can rewrite committed generated files, and codegen auto-sync runs the project's configured formatters (external programs) when something changed. Set `CUENV_AUTOSYNC=0` to turn it off. With `CI` set nothing is written ([#680](https://github.com/cuenv/cuenv/pull/680)).
- **A stale `scripts.gen.cue` fails CI.** With `CI` set, and in `cuenv ci`, a `scripts.gen.cue` that does not match the project's `scriptDirs` is an error. Run `cuenv sync scripts` and commit the file. A local `cuenv ci` on a fresh checkout with no `.cuenv` store fails the same way until the file is synced ([#680](https://github.com/cuenv/cuenv/pull/680)).
- **New error for a missing program, for every task.** A task whose program is not installed now fails with ``program `X` was not found; install it or provide it through the project runtime``. Anything that matched the old error text needs updating ([#680](https://github.com/cuenv/cuenv/pull/680)).
- **A misnamed `watch.rebuild` task fails `cuenv up`.** Rebuild tasks are now resolved before any service starts, so a name that matches no task stops `cuenv up` immediately instead of failing on the first change ([#672](https://github.com/cuenv/cuenv/pull/672)).
- **GitHub matrix tasks with a dimension other than `arch` are refused.** They used to emit no jobs and no error. `cuenv sync ci` now also refuses a workflow whose `needs` names a job it does not define ([#669](https://github.com/cuenv/cuenv/pull/669)).
- **Write commands refuse an inconclusive S3 public-bucket check.** If the unsigned probe keeps getting a 5xx, 408, 429 or a transport failure after three retries, `migrate` and other write commands stop instead of treating the bucket as private. Read-only commands warn and check again next time ([#664](https://github.com/cuenv/cuenv/pull/664)).

## Features

- **Scripts as tasks.** `scriptDirs` on a project lists directories of scripts. cuenv writes what it finds to `scripts.gen.cue` as `scripts: [name]: #ProjectScript`, and each script runs as a task of the same name. Projects extend entries by name (`dependsOn`, `params`, `interpreter`), and tasks and pipelines reference them as `scripts.<name>`. With `params`, arguments are checked and passed as positionals and `--name value`. Interpreters: `bash`, `sh`, `fish`, `nu`, `python`, `python3`, `python3.N` and `bun`, detected from the shebang or an unambiguous extension. New command: `cuenv sync scripts` (`--check`, `--dry-run`, `-A`), which runs first in `cuenv sync`. See `examples/scripts` and the task scripts how-to ([#680](https://github.com/cuenv/cuenv/pull/680), [#677](https://github.com/cuenv/cuenv/issues/677)).
- **Nested infrastructure output selectors.** A reference can read one scalar inside a list, tuple or object output, such as `outputs.result[0].id`. A position the provider did not return fails the plan and names the path. Generated `#Outputs` now type list and object outputs. Digests of existing top-level references are unchanged ([#676](https://github.com/cuenv/cuenv/pull/676), [#597](https://github.com/cuenv/cuenv/issues/597)).
- **cuetty opens terminal hyperlinks** with Ctrl-click (Linux) or Cmd-click (macOS), for OSC 8 links and printed HTTP(S) URLs ([#679](https://github.com/cuenv/cuenv/pull/679)).

## Fixes

- **S3 public-bucket check no longer fails open**: a 5xx, 429, timeout or lost connection no longer counts as private ([#664](https://github.com/cuenv/cuenv/pull/664)).
- **macOS task processes die with cuenv**: tasks run under the `__supervise` wrapper, so a `kill -9` or OOM kill of cuenv no longer leaves them running. `__supervise` now re-raises the child's signal instead of exiting 127 ([#665](https://github.com/cuenv/cuenv/pull/665)).
- **`watch.rebuild` tasks run**: on a watched change the supervisor runs the rebuild tasks first, then restarts or sends SIGHUP. A failed rebuild keeps the running process ([#672](https://github.com/cuenv/cuenv/pull/672)).
- **`cuenv sync codegen --diff` never writes**: formatters ran in fix mode under `--diff`. Formatters also receive root-relative paths, so a relative `--path` works ([#681](https://github.com/cuenv/cuenv/pull/681)).
- **Contributor steps get their declared secrets** in generated GitHub workflows ([#673](https://github.com/cuenv/cuenv/pull/673)).
- **Contributor phase steps follow `dependsOn`**, and negative priorities stay in bootstrap ([#675](https://github.com/cuenv/cuenv/pull/675)).
- **Dependents of a GitHub matrix task need every variant job** ([#669](https://github.com/cuenv/cuenv/pull/669)).
- **Terraform 1.12 is reported to providers**, matching the resource identity support cuenv implements ([#670](https://github.com/cuenv/cuenv/pull/670)).
- **cuetty**: Metal shaders compile at runtime on macOS, so builds work with only the Xcode Command Line Tools ([#642](https://github.com/cuenv/cuenv/pull/642)); word and line selection, accelerating drag scroll, and Page Up, Page Down and Insert reach the PTY ([#671](https://github.com/cuenv/cuenv/pull/671)).
- This repository's docs and cross tasks keep their tool caches ([#674](https://github.com/cuenv/cuenv/pull/674)). Output references are covered by a cache-key test ([#666](https://github.com/cuenv/cuenv/pull/666)).

## Security

- Patched advisories, including six critical: wasmtime 49 (via extism 1.41), zip 9, quinn-proto 0.11.19, tokio 1.54.1, rustls 0.23.46 in cuetty, url 2.5.9, zstd 0.13.5, and test-only grpc 1.85 and golang.org/x/net 0.63 ([#682](https://github.com/cuenv/cuenv/pull/682)).
- quinn-udp 0.5.16, memmap2 0.9.12, faster-hex 0.10.1 and lru 0.18.5. CI now audits against the live RustSec database daily and on every push to `main`, with exceptions in `.cargo/audit.toml` ([#683](https://github.com/cuenv/cuenv/pull/683)).
