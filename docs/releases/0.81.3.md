# cuenv 0.81.3

## Fixes

- A Nix runtime with the default flake (`.`) now resolves the flake the way Nix does: from the project directory up to the nearest `flake.nix`, stopping at the CUE module root ([#737](https://github.com/cuenv/cuenv/pull/737)). A monorepo can set `runtime: schema.#NixRuntime` once in its root `env.cue`; `cuenv sync` locks every project that has no flake of its own against the root `flake.lock`, and a project with its own `flake.nix` still uses it. `path:` references stay exact. Each project keeps its own `cuenv.lock` entry.
- A `nix print-dev-env` hook with the default flake now re-runs when the `flake.nix` or `flake.lock` it resolves above the project changes, so editing the root flake refreshes the shell in every project that inherits it.
- `cuenv ci` selects every pipeline task of a project whose default-flake runtime resolves to a changed `flake.nix` or `flake.lock`, including a flake inherited from the repository root.
