# Cuetty product context

## Register

product

## Users

Developers working in a terminal, switching between tabs and running commands
or Cuenv tasks in the current directory.

## Product Purpose

Provide a native terminal with a dependable shell and make project-aware tools
available without taking attention away from terminal work.

## Brand Personality

Restrained, practical, and direct. Controls should feel at home beside the
terminal rather than compete with it.

## Anti-references

Avoid decorative chrome and separate controls that duplicate the same action.
The existing Ghostty-inspired presentation is the visual reference.

## Design Principles

- Keep the terminal and its established keyboard behavior dependable.
- Make common actions discoverable and efficient from the keyboard.
- Keep project actions tied to the active tab and its working directory.
- Reuse Cuenv's existing task execution rather than duplicating it.

## Accessibility & Inclusion

Support keyboard operation and reduced motion. Maintain the existing theme
contrast contract of at least 4.5:1 for body and metadata text.
